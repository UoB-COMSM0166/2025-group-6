## Week 6: Progress Update & Finalization

**Overview:**  
In this week, significant progress has been made towards finalizing key features and resolving bugs. The project has progressed smoothly, and we are nearing a more polished version of the game with completed features and improvements.

**Actions Taken:**  
- **Game Features & Enhancements:**  
  - **Powerups**: Implemented powerups that are activated when a player scores two consecutive goals. This adds a new layer of strategy and excitement to the game.
  - **Pause Button**: Integrated a pause button within the game screen, giving players control over pausing the game mid-play.
  - **Exit Button**: Added an exit button functionality to allow users to quit the game whenever needed.
  - **Winner Page**: The **Winner Page** has been implemented to show the winner once a player wins, offering a more engaging user experience.
  - **Landing Page**: The landing screen is now set up for players to start the game easily.
  - **Sound Bug Fix**: Fixed the issue where the game sound didn't pause when the game was paused.

- **Bug Fixing:**  
  - Fixed the issue where the puck occasionally passed through the mallet during gameplay.
  - Resolved the issue of **different mallet colors** for two players to ensure a smoother experience.

- **Visual Improvements:**  
  - Added a more **attractive graphics design* * for the game, making it visually appealing for the users.
